# 超大城市面向自然灾害的安全韧性评价——北京试点数据

本仓库用于备份《系统建立超大城市面向自然灾害的安全韧性评价指标体系》研究过程中收集的**北京试点数据**，全部来自政府公开渠道，可追溯、可核验。

## 数据来源

- 北京市公共数据开放平台（data.beijing.gov.cn）：气象站月值、城镇公共供水厂月供水量、城市雨情、雨量、积水监测
- 《北京区域统计年鉴2025》在线版（nj.tjj.beijing.gov.cn）
- 应急管理部、北京各区财政局/统计局官网（公共安全支出决算）
- 应急管理部历年"全国综合减灾示范社区"名单公告

所有具体URL见 `公共安全支出来源链接清单.md` 与 `月度数据/数据清单与来源.md`，均已逐一访问核验。
