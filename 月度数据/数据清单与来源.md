## 三、关键发现与限制

1. **气象站月值数据只有15个月**（2023-12起），且缺2024年7月。要拼36个月需另找更早历史（如中国气象数据网 http://data.cma.cn 的月值/日值数据，或气象局逐年归档）。
2. **供水厂月供水量是唯一"连续90个月+"的月度数据集**（2018-11~2026-05），可直接支撑"区县×月份"表的水务维度；14座水厂可按地理位置归属到区。
3. **雨量/积水/雨情数据集下载接口都限10000条**：雨量只拿到最近1天；积水只拿到2023-05~2024-05；雨情被Excel 104万行截断到2023-08。完整历史需调用接口按时间分段拉取（接口文档见 dataDoc.jsp），或定期归档。
4. 平台下载需登录（账号：刘倩倩/北京通扫码），key=1791454307955 可用于API调用（唯一标识码，勿外传）。

## 七、三事件对比数据集（已完成 2026-10-08）

文件：`北京暴雨灾害事件对比数据集.xlsx`（6个sheet）

北京三次重大暴雨灾害事件对比（2012"7·21" / 2023"23·7" / 2025"25·7"）：

| Sheet | 内容 |
|---|---|
| 事件概览对比 | 时间、成因、历史定位、重灾区域、灾害类型 |
| 降雨强度对比 | 全市平均、单站最大、小时雨强、持续时间（23·7最强：276.5mm/744.8mm/111.8mm/h） |
| 冲击影响对比 | 受灾人口（160.2万/129万/30余万）、死亡（79/33/30）、转移（5万/34.4万/8万）、房屋、损失、中断 |
| 恢复时间线对比 | 积水消退、交通、通信、供电、供水恢复时间（逐次加速） |
| 韧性解读 | 恢复速度提升、生命损失下降、空间异质性、强度-损失关系、事件频率上升 |
| 数据来源 | 全部官方通报URL（气象局、市政府、水务局、新华网、央广网、北京日报等） |

**核心发现（可直接写进论文）**：
1. 恢复速度逐次提升：7·21积水65小时才退；23·7供水供电通信8~9天全面恢复；25·7供电供水通信3~4天基本恢复——体现韧性"学习适应"机制；
2. 生命损失下降：死亡79→33→30，且23·7雨强远超7·21——预警与转移有效性是韧性核心；
3. 空间异质性：7·21主城+房山、23·7西部山区、25·7北部山区——必须区县粒度分析；
4. 事件频率上升：2012→2023→2025，极端降雨趋频趋强。
